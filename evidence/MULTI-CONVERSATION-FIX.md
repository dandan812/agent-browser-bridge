# 多对话标签页管理修复与验证

验证日期：2026-11-10。

## 范围

隔离单位是 PI 的不同顶层对话。多个对话独立管理后台页面，共享所选浏览器配置的已有登录态。同一对话内每个子 Agent 自动独立分配连接不属于当前需求。

## 修复

- 使用独立的 `Agent Browser Bridge · …` 标签组前缀，避免官方 Playwright 扩展启动时清理 `Playwright · …` 旧组而导致受控页面引用丢失。未禁用或修改官方扩展。
- 关闭最后一个标签页后保留空会话连接，可继续创建页面。
- 正确处理先 debugger detach、后 tabs.onRemoved 的事件顺序，释放删除页面的归属与重连状态。
- 最后一个页面离开组或被删除后清理已失效的组 ID，后续创建新组。

## 使用边界

同一浏览器配置的账号状态共享，不是账号沙箱。网站验证码、权限、文件选择等系统弹窗可能需要人工处理。F12 能力为明确提供的诊断接口，不是所有 DevTools 面板的完整替代。

重新构建扩展后需重新加载扩展；本机已经重载并完成上述个人配置验证。此公开说明不包含配对密钥、个人配置标识、进程信息或原始浏览器日志。
